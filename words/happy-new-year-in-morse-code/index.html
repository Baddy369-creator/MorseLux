How to send “Happy New Year” in Morse code

“Happy New Year” has 18 dots and 16 dashes. At 15 words per minute it takes about 10.3 seconds. Tap short for a dot and three times as long for a dash, with a short pause between the letters and a longer one between words. Play it as sound or light in the Morse code translator, or type it in WhatsApp with the Morse keyboard for iPhone.
