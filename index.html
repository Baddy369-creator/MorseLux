How Morse code works

Morse code writes every letter as a short pattern of two signals: a short one, the dot (“dit”), and a long one, the dash (“dah”). The rhythm matters as much as the signals, so Morse can be sent with anything that can be switched on and off: a sound, a light, a vibration, a tap on a table.

ElementLength
Dot ·1 unit
Dash –3 units
Gap inside a letter1 unit
Gap between letters3 units
Gap between words7 units

The most common letters got the shortest codes: E is a single dot, T a single dash. That is why learning Morse code usually starts with E and T.

Frequently asked questions

How do I translate text into Morse code?

Type or paste your text into the Text box. The Morse code appears instantly in the second box: letters are separated by a space and words by a slash (/). Press “Play sound” to hear it.

How do I decode Morse code into text?

Type or paste the Morse code into the Morse code box using dots (.) and dashes (-). Put a space between letters and a slash (/) between words. You can also paste Morse into the Text box; it is recognised and decoded automatically.

What do the dots and dashes mean?

A dot (also called “dit”) is a short signal and a dash (“dah”) is three times as long. Every letter and number has its own pattern, for example A is ·– and S is ···. See the full Morse code alphabet.

What is WPM?

WPM means words per minute, the standard way to measure Morse speed. It is based on the word PARIS. At 15 WPM a dot lasts 80 milliseconds. Beginners often listen at 15–20 WPM with longer gaps between letters.

Can I send a secret message in Morse code?

Yes. Type your message and press “Share as secret”. Your friend gets a link that shows only the Morse code; they can listen to it and try to decode it before revealing the answer.

Is this Morse code translator free?

Yes, completely free, with no sign-up and no ads. Everything runs in your browser; your text is not sent to a server.

Which characters are supported?

All letters A–Z, numbers 0–9, the common punctuation marks (. , ? ' ! / ( ) & : ; = + - _ " $ @) and the extra letters Ä, Ö, Ü, ß, Ñ, É, À and È. Accented letters without their own code are sent as the plain letter.
