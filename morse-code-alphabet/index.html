Tips for learning the alphabet

  • Listen, don't count. At real speed you cannot count dots and dashes; you hear each letter as one sound pattern.
  • Opposites help: A (·–) and N (–·), D (–··) and U (··–), G (––·) and W (·––) are mirror images.
  • Practise in short sessions. Ten to fifteen minutes a day works better than one long session a week.
  • Use it. Type a word into the Morse code translator and try to hear the letters before you read them.

Frequently asked questions

How many letters does the Morse code alphabet have?

The International Morse Code has codes for the 26 letters A–Z, the ten digits 0–9 and around 18 punctuation marks. Several languages add their own letters, such as Ä, Ö and Ü in German or Ñ in Spanish.

What is the easiest way to memorise the Morse alphabet?

Learn the sound, not the picture. Listen to each letter as one rhythm instead of counting dots and dashes, and start with only two letters (E and T), adding one more when you recognise them without thinking. Our step-by-step guide explains how.

Which Morse code letters are the shortest?

E (·) and T (–) are the shortest because they are the most common letters in English. I (··), A (·–), N (–·) and M (––) follow with two signals each.

Is there a Morse code for spaces?

There is no signal for a space; a space is a pause. Between letters you wait three units, between words seven. In writing, letters are separated by a space and words by a slash (/).

Is American Morse code different?

Yes. The original American Morse code used in early US telegraphy had different codes and internal gaps. Today almost everyone, including radio amateurs, uses the International Morse Code shown on this page.

Can I print the Morse code chart?

Yes. Use your browser's print function (Ctrl+P or ⌘P); the page prints as a clean black-and-white chart without menus.
