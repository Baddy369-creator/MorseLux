Set up in one minute

  1. Download MorseLux from the App Store. Download on theApp Store
  2. Open Settings → General → Keyboard → Keyboards.
  3. Tap Add New Keyboard… and choose MorseLux.
  4. Optional: tap MorseLux and turn on Allow Full Access so the keyboard can use your app settings, the tap key (Pro) and the typing vibration.
  5. In any app, tap the globe key 🌐 to switch to the Morse keyboard.

What is free, what is Pro?
Free: dot and dash keys and the letters-to-Morse mode – with no time limit. MorseLux Pro unlocks the tap key and all lessons in the app (monthly or yearly subscription – yearly with a 1-week free trial – or a one-time purchase; price in the App Store).
🔒 Your messages stay with you
The keyboard does not store or send what you type, does not read the clipboard and works without an internet connection. It needs Full Access only for your app settings, the Pro unlock (tap key) and the typing vibration. Details are in the privacy policy.

Frequently asked questions

How do I type Morse code on my iPhone?

Add a Morse keyboard: install MorseLux, open Settings → General → Keyboard → Keyboards → Add New Keyboard and choose MorseLux. Then switch to it with the globe key in any app. Without an app you can write Morse in the online translator and copy it.

Is there a free Morse code keyboard for iPhone?

Yes. The MorseLux keyboard is free: dot and dash keys and the letters-to-Morse mode cost nothing; only the tap key is part of MorseLux Pro. Google's Gboard also has a free Morse layout, but, according to Google's help pages, only for English (US).

How do I add a Morse keyboard to my iPhone?

Install MorseLux, then open Settings → General → Keyboard → Keyboards → Add New Keyboard and choose MorseLux. In any app, hold or tap the globe key to switch to it.

Does the Morse keyboard work in WhatsApp?

Yes. It is a system keyboard, so it works in WhatsApp, Messages, Instagram, Telegram, Mail, Notes and any other app with a text field.

Why does the keyboard ask for Full Access?

The keyboard needs Full Access only to use your settings from the app, the Pro unlock (tap key) and the typing vibration. It does not store what you type, does not read the clipboard and sends nothing over the internet. Without Full Access the dot and dash keys and letters-to-Morse still work with their default settings.

Can I type normal letters and send Morse?

Yes. In “Letters to Morse” mode you type normally and the keyboard writes dots and dashes. It is the easiest way to send secret messages to friends.

Is the Morse keyboard free?

The dot and dash keys and the “Letters to Morse” mode are free. The tap key, where you tap one key short and long like a telegraph key, is part of MorseLux Pro.

Is there a Morse keyboard for Android?

MorseLux is for iPhone. On Android, Google's Gboard has a Morse code layout. On any phone you can also use the online translator and copy the Morse code.

Do I need to know Morse code to use the keyboard?

No. In letters-to-Morse mode you type normally and the keyboard writes the Morse code. If you want to learn it, the app has daily lessons and there is a free Morse trainer on this site.
