Ideas para tu nombre en código Morse

📿

Pulseras y joyas

Cuentas pequeñas para los puntos, cuentas largas para las rayas y un separador entre letras. También quedan bien en chapas y anillos grabados.

✒️

Tatuajes

Un nombre, una fecha o una palabra que solo entienden quienes saben leerla. Deja espacios claros entre letras para que se pueda leer.

🎁

Regalos y tarjetas

Una fecha de nacimiento, las iniciales de una pareja o el nombre de un niño en Morse en una tarjeta, una taza o un marco.

Preguntas frecuentes

¿Cómo escribo mi nombre en código Morse?

Escribe tu nombre en el campo de arriba. Cada letra aparece con su código Morse debajo. Por escrito, las letras se separan con un espacio y las palabras (por ejemplo nombre y apellido) con una barra: LUCIA es ·–·· ··– –·–· ·· ·–.

¿Cómo hago una pulsera en código Morse?

Usa una cuenta pequeña y redonda para cada punto, una cuenta larga (o un tubo) para cada raya y otra cuenta o un nudo entre letras. Apunta el código antes con esta herramienta y compruébalo letra a letra antes de enhebrar.

¿Es buena idea un tatuaje con mi nombre en Morse?

A mucha gente le encanta porque parece un dibujo pero tiene un significado oculto. Asegúrate de que los espacios entre letras se vean bien; sin ellos, los puntos y rayas pueden leerse como otras letras. Compara el diseño final con el alfabeto Morse antes de tu cita.

¿Qué pasa con la Ñ y las tildes?

La Ñ y la É tienen su propio código Morse, que esta herramienta usa. Las demás vocales con tilde (Á, Í, Ó, Ú) se escriben como la letra sin tilde.

¿Puedo descargar mi nombre en código Morse?

Sí. Pulsa «Descargar imagen» para guardar un PNG con tu nombre y el código Morse debajo de cada letra, listo para imprimir o enviar al joyero o tatuador.
