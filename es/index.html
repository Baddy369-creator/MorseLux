Cómo usar el traductor de código Morse

  1. Escribe tu texto. El código Morse aparece mientras escribes. Si pegas Morse en el campo de texto, se traduce automáticamente.
  2. O escribe en Morse. Usa los botones · y – (o las teclas . y -). Un espacio termina una letra y una barra (/) termina una palabra.
  3. Envíalo. Reprodúcelo con sonido, haz parpadear la pantalla como una lámpara de señales, haz vibrar el móvil, descarga un archivo WAV o comparte un enlace secreto.

Cómo funciona el código Morse

El código Morse escribe cada letra como un patrón de dos señales: una corta, el punto («ti»), y una larga, la raya («ta»). El ritmo es tan importante como las señales, por eso se puede transmitir con cualquier cosa que se encienda y se apague: un sonido, una luz, una vibración o unos golpes.

ElementoDuración
Punto ·1 unidad
Raya –3 unidades
Pausa dentro de una letra1 unidad
Pausa entre letras3 unidades
Pausa entre palabras7 unidades

Las letras más frecuentes tienen los códigos más cortos: la E es un punto y la T una raya. Por eso, para aprender código Morse se suele empezar con la E y la T.

Preguntas frecuentes

¿Cómo traduzco un texto a código Morse?

Escribe o pega tu texto en el campo «Texto». El código Morse aparece al instante en el segundo campo: las letras se separan con un espacio y las palabras con una barra (/). Pulsa «Reproducir» para escucharlo.

¿Cómo descifro código Morse?

Escribe el código con puntos (.) y rayas (-) en el campo «Código Morse», con un espacio entre letras y una barra (/) entre palabras. También puedes pegar Morse en el campo de texto: se reconoce y se traduce automáticamente.

¿Qué significan los puntos y las rayas?

Un punto («ti») es una señal corta y una raya («ta») dura tres veces más. Cada letra tiene su propio patrón, por ejemplo A = ·– y S = ···. Consulta el alfabeto Morse completo.

¿Qué significa WPM?

WPM significa «words per minute», palabras por minuto, la medida habitual de la velocidad en Morse. Se basa en la palabra PARIS. A 15 WPM un punto dura 80 milisegundos.

¿Puedo enviar un mensaje secreto en Morse?

Sí. Escribe tu mensaje y pulsa «Compartir como reto». Tu amigo recibe un enlace que solo muestra el código Morse; puede escucharlo e intentar descifrarlo antes de ver la respuesta.

¿El traductor es gratis?

Sí, totalmente gratis, sin registro y sin anuncios. Todo funciona en tu navegador; tu texto no se envía a ningún servidor.

¿Funciona con la Ñ y los acentos?

Sí. La Ñ tiene su propio código (––·––). Las vocales con tilde (Á, Í, Ó, Ú) se envían como la letra sin tilde, y la É tiene código propio (··–··).
