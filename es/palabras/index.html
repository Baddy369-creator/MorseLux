Preguntas frecuentes

¿Cómo escribo mi propia palabra en código Morse?

Escríbela en el traductor de código Morse: el código aparece al instante, con sonido. Para nombres está tu nombre en código Morse, con una imagen para guardar.

¿Cómo se separan las palabras en código Morse?

Entre dos letras hay una pausa corta (se escribe con un espacio) y entre dos palabras una más larga (se escribe con una barra /).
