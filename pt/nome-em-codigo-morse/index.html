Seu nome em código Morse

Digite um nome, uma palavra ou uma data e veja em código Morse, letra por letra. Ouça, copie ou baixe como imagem para uma pulseira, uma tatuagem, uma gravação ou um cartão.

Ideias para o seu nome em código Morse

📿

Pulseiras e joias

Miçangas pequenas para os pontos, compridas para os traços e um espaçador entre as letras. Também funciona em anéis e plaquinhas gravadas.

✒️

Tatuagens

Um nome, uma data ou uma palavra que só quem sabe consegue ler. Deixe espaços claros entre as letras para continuar legível.

🎁

Presentes e cartões

Escreva uma data de nascimento, as iniciais de um casal ou o nome de uma criança em Morse em um cartão, uma caneca ou um quadro.

Perguntas frequentes

Como escrevo meu nome em código Morse?

Digite o nome no campo acima. Cada letra aparece com seus pontos e traços, e você pode ouvir, copiar ou baixar o resultado como imagem.

Como faço uma pulseira com código Morse?

Use uma miçanga pequena para cada ponto, uma comprida para cada traço e um espaçador entre as letras. A imagem baixada serve de molde.

Nomes com acento funcionam?

Sim. Letras com acento como Á, Ã ou É são escritas como a letra simples; o Ç tem um sinal próprio.

Posso usar a imagem livremente?

Sim, a imagem é sua: para uso pessoal, presentes, tatuagens ou gravações.
