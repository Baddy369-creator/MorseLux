Como funciona o tradutor de código Morse

  1. Digite o texto. O código Morse aparece enquanto você digita. Morse colado no campo de texto é traduzido automaticamente.
  2. Ou digite Morse. Com as teclas · e – (ou . e -). Um espaço encerra a letra e uma barra (/) encerra a palavra.
  3. Envie. Toque como som, faça a tela piscar como uma lâmpada de sinais, faça o celular vibrar, salve um arquivo WAV ou compartilhe um link secreto.

Como funciona o código Morse

O código Morse escreve cada letra como um padrão de dois sinais: um curto, o ponto («di»), e um longo, o traço («dá»). O ritmo importa tanto quanto os sinais. Por isso dá para enviar Morse com tudo o que liga e desliga: som, luz, vibração ou batidas.

ElementoDuração
Ponto ·1 unidade
Traço –3 unidades
Pausa dentro da letra1 unidade
Pausa entre letras3 unidades
Pausa entre palavras7 unidades

As letras mais comuns do inglês receberam os sinais mais curtos: E é um ponto, T é um traço. Por isso o app começa as lições com E e T; o treinador deste site segue o método Koch e começa com K e M.

Perguntas frequentes

Como traduzo um texto para código Morse?

Digite ou cole o texto no campo «Texto». O código Morse aparece na hora no segundo campo: as letras são separadas por um espaço e as palavras por uma barra (/). Com «Tocar som» você ouve o resultado.

Como decifro código Morse?

Digite o código com pontos (.) e traços (-) no campo «Código Morse», com um espaço entre as letras e uma barra (/) entre as palavras. Você também pode colar o Morse no campo de texto: ele é reconhecido e traduzido automaticamente.

O que significam o ponto e o traço?

O ponto é um sinal curto e o traço dura três vezes mais. Cada letra tem o seu padrão, por exemplo A = ·– e S = .··· Todos os sinais estão no alfabeto Morse.

Posso mandar uma mensagem secreta em código Morse?

Sim. Escreva a mensagem e toque em «Enviar como mensagem secreta». Seu amigo recebe um link que mostra só o código Morse; ele pode ouvir e tentar decifrar antes de ver a resposta.

O tradutor de código Morse é gratuito?

Sim, totalmente gratuito, sem cadastro e sem anúncios. Tudo roda no seu navegador; seu texto não é enviado a nenhum servidor.

Dá para escrever em Morse no celular?

Sim. Aqui no site você digita pontos e traços com as teclas abaixo do campo Morse. Para escrever em Morse no WhatsApp, iMessage ou Instagram existe o teclado Morse para iPhone.
