Comment fonctionne le traducteur morse

  1. Tapez un texte. Le code morse s'affiche pendant que vous écrivez. Le morse collé dans le champ de texte est traduit automatiquement.
  2. Ou tapez du morse. Avec les touches · et – (ou . et -). Un espace termine la lettre et une barre oblique (/) termine le mot.
  3. Envoyez-le. Jouez-le en son, faites clignoter l'écran comme une lampe de signalisation, faites vibrer le téléphone, enregistrez un fichier WAV ou partagez un lien secret.

Comment fonctionne le code morse

Le code morse écrit chaque lettre comme un motif de deux signaux : un court, le point (« ti »), et un long, le trait (« ta »). Le rythme compte autant que les signaux. C'est pourquoi on peut envoyer du morse avec tout ce qui s'allume et s'éteint : son, lumière, vibration ou coups frappés.

ÉlémentDurée
Point ·1 unité
Trait –3 unités
Pause dans une lettre1 unité
Pause entre lettres3 unités
Pause entre mots7 unités

Les lettres les plus fréquentes en anglais ont reçu les signes les plus courts : E est un point, T est un trait. C'est pourquoi l'app commence ses leçons par E et T ; l'entraînement de ce site suit la méthode Koch et commence par K et M.

Questions fréquentes

Comment traduire un texte en morse ?

Tapez ou collez le texte dans le champ « Texte ». Le code morse s'affiche aussitôt dans le second champ : les lettres sont séparées par un espace et les mots par une barre oblique (/). « Jouer le son » vous fait entendre le résultat.

Comment déchiffrer du code morse ?

Tapez le code avec des points (.) et des tirets (-) dans le champ « Code morse », avec un espace entre les lettres et une barre oblique (/) entre les mots. Vous pouvez aussi coller le morse dans le champ de texte : il est reconnu et traduit automatiquement.

Que signifient le point et le trait ?

Le point est un signal court et le trait dure trois fois plus longtemps. Chaque lettre a son motif, par exemple A = ·– et S = .··· Tous les signes sont dans l'alphabet morse.

Peut-on envoyer un message secret en morse ?

Oui. Écrivez le message et touchez « Envoyer en message secret ». Votre ami reçoit un lien qui n'affiche que le code morse ; il peut l'écouter et essayer de le déchiffrer avant de voir la réponse.

Le traducteur morse est-il gratuit ?

Oui, entièrement gratuit, sans inscription et sans publicité. Tout se passe dans votre navigateur ; votre texte n'est envoyé à aucun serveur.

Peut-on écrire en morse sur un téléphone ?

Oui. Sur ce site, vous tapez les points et les traits avec les touches sous le champ morse. Pour écrire en morse dans WhatsApp, iMessage ou Instagram, il existe le clavier morse pour iPhone.
