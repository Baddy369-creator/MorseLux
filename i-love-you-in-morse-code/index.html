How do you write “I love you” in Morse code?

How do I tap “I love you” in Morse code?

Tap short for a dot and three times as long for a dash, pause briefly between letters and a bit longer between words. Many couples tap it on each other's hand — or simply send it in a chat with the Morse keyboard.
