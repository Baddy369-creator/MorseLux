Frequently asked questions

How do I write my name in Morse code?

Type your name into the box above. Each letter appears with its Morse code underneath. In writing, letters are separated by a space and words (for example first and last name) by a slash: EMMA is .· –– –– ·–

How do I make a Morse code bracelet?

Use a small round bead for each dot, a long bead (or a tube bead) for each dash and a different bead or a knot between letters. Write down the code first with this tool and check it letter by letter before you thread.

Is a Morse code tattoo of my name a good idea?

Many people love them because they look like a pattern but carry a hidden meaning. Make sure the gaps between letters are clearly visible — without them, the dots and dashes can be read as different letters. Check the final design against the Morse alphabet before your appointment.

What about letters like é, ü or ñ?

Ü, Ñ, É and a few others have their own Morse codes, which this tool uses. Other accented letters are written as the plain letter.

Can I download my name in Morse code?

Yes. Press “Download image” to save a PNG of your name with the Morse code underneath each letter, ready to print or send to a jeweler or tattoo artist.
